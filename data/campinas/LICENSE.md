# Dados de Campinas

`source.osm.json.gz` é um recorte original de OpenStreetMap; `graph.json` é sua base derivada.

Licença dos dados: Open Database License 1.0 (ODbL),
https://opendatacommons.org/licenses/odbl/1-0/ . A licença MIT do código não substitui a ODbL.
Consulta, timestamp e SHA-256 do original estão no grafo. O original é distribuído junto
do derivado para permitir reconstrução. `python tools/import_osm.py` o reproduz offline.

Os pontos e a demanda são sugestões de simulação, não uma base oficial de transporte.
Identidade municipal: IBGE, Campinas/SP, código 3509502.
https://www.ibge.gov.br/cidades-e-estados/sp/campinas
Não distribuímos limites administrativos nem estatísticas populacionais nesta fase.
